## 2. Sistema de cuotas (lo que pediste: parar sin cortar el flujo)

`rust-core/src/quota_guard.rs` (nuevo, 18.666 B):

* **Observa**: parsea los errores reales del proveedor — 429, `quota exceeded`,
  `insufficient credits`, 402, `resets at <epoch|5pm>`, `retry after 42` — y
  registra el uso real (tokens).
* **Niveles**: `normal` → `aviso` (80 %) → `ahorro` (90 %) → `pausa` (98 %).
  Umbrales por entorno: `MD_QUOTA_AVISO` / `MD_QUOTA_AHORRO` / `MD_QUOTA_PAUSA`.
* **Aviso con coste CERO**: el estado viaja **dentro de la respuesta del chat**
  (`ChatResult.quota`) ⇒ el agente sabe cuánto queda sin pedirlo y **sin gastar
  un token extra** en una llamada aparte.
* **Snapshot compacto**: ~70 tokens (`{"p":"minimax","n":"aviso","w":{"5h":82},"r":1.3}`)
  frente a ~400 del completo.
* **Tool MCP** `quota_status` + **endpoint** `GET /api/quota`.
* En `pausa`, el proveedor queda con `reset_at` y las tareas se pausan: **no se
  corta el flujo a mitad**.

## 3. Cola de tareas compartida (no se pierde el trabajo)

`rust-core/src/task_scheduler.rs` + `rust-core/src/task_sync.rs` (nuevo) +
`rust-core/src/bin/md-tasks.rs` (CLI) + tool MCP `task_queue`:

* `repartir_por_nodo(nodo, max, lease)` — asigna con lease.
* `migrar_tareas(desde, hacia)` — **handoff**: el trabajo pasa a otro nodo.
* `expirar_leases()` — el nodo que muere con una tarea **no la pierde**.
* `pausar_por_cuota(nodo, reset_at, motivo)` — pausa elegante.
* `merge_tasks()` — fusión por id; gana el estado más avanzado
  (`done > running > paused > pending`) ⇒ una tarea terminada en otro nodo no
  se re-ejecuta aquí.
* `sincronizar_drive()` — sube `tasks-<nodo>-<ts>.json` a la carpeta **privada**
  de Drive (`megadaemon-backup/cola-tareas`), lista los de los demás nodos,
  descarga y fusiona. **Sincronía real entre nodos.**
* `claim` **no devuelve tareas** si la cuota está en pausa: lo dice y por qué.

## 4. curl nativo (el móvil no tiene curl ni wget)

MEDIDO: `toybox wget` → "Unknown command" (rc=127). Termux no puede estar en
el camino crítico ⇒ el daemon necesitaba HTTP propio.

`rust-core/src/http_transfer.rs` (nuevo) + `rust-core/src/bin/md-curl.rs` +
tool MCP `http_fetch`:

* descarga con **resume** (`Range`), reintentos con backoff, timeout;
* verificación por **tamaño y SHA-256** (y BLAKE3, más rápido);
* **descargas en paralelo** con MB/s y ETA reales;
* subida POST/PUT; `HEAD` para cabeceras;
* **descarga atómica**: se escribe en `<destino>.part` y sólo se renombra al
  terminar bien ⇒ **el destino nunca queda corrupto** y el `.part` sirve para
  reanudar.

## 5. Accesibilidad de la flota al móvil: el bloqueo real

MEDIDO: el móvil está **VIVO** (`GET /health` → 200) pero `/mcp` devolvía
**403 "API key invalida"**: la key del PC no coincide con la vigente del móvil
(el supervisor reinició el daemon con otra). El cliente sólo decía "el móvil no
respondió", sin pista ⇒ **la flota estuvo horas a ciegas**.

Corregido:
* `/health` publica `key_fp` (fnv1a64 de la key vigente, **no** la key) y
  `cuota` (snapshot compacto).
* `tools/md_mcp.sh` compara y dice: *"el móvil está VIVO y espera la key con
  fingerprint X"*; además acepta el campo `token` (no sólo `auth_token`), que
  es lo que `/api/session/exchange` devuelve de verdad.
* `tools/sincronizar-key.sh`: se ejecuta **en el móvil**, deja la key vigente en
  todos los `state_dir` conocidos (0600) e imprime el fingerprint para
  comparar.

## 7. Bugs reales encontrados y corregidos hoy

1. **CSC no-op** (`megadaemon_csc_recording`): el `cscfeature.xml` del móvil va
   comprimido con **OMC** (rotación+XOR+gzip). Decodificado: 30 features y
   `CscFeature_VoiceCall_ConfigRecording = "RecordingAllowedByMenu,disclaimer_latin"`
   ⇒ **Samsung ya permite grabar desde el menú, con aviso legal**. El módulo
   instalado tenía el **mismo sha256** que el original ⇒ **no cambiaba nada**.
   Ahora `csc_patch::patch()` **verifica en caliente y en frío** ⇒ un módulo
   no-op es imposible.
2. **`magisk_module.rs` truncado**: el agente murió escribiendo ⇒ cadena sin
   cerrar ⇒ **main no compilaba** (E0765). Reparado.
3. **`md_mcp.sh`**: leía `auth_token` cuando el daemon devuelve `token`.
4. **`self_update`**: existía como CLI pero **el daemon no se auto-actualizaba**.
   Ahora hay hilo permanente (6 h + jitter), SHA-256, instalación atómica,
   `.prev` para rollback y salida con código 10 para que el supervisor relance.
5. **Gateway**: `POST /v1/chat/completions` + dialecto **GEMINI** (el idioma de
   Antigravity) ⇒ `llm_gateway.rs` pasó de 254 a 566 líneas.
